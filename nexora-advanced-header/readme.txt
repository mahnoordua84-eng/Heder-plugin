== Description ==

Nexora Advanced Header is a premium, fully customizable website header system for WordPress and WooCommerce. It includes mega menu support, sticky header, animated bottom line, mini cart, social icons, and full responsive/RTL support.

= Features =

* Announcement bar with animated scrolling text
* Multi-level dropdown and mega menu navigation (2-5 columns)
* AJAX-ready WooCommerce mini cart with live counter
* Sticky header with shrink and shadow on scroll
* Animated gradient bottom line with moving text
* Full mobile drawer menu with accordion submenus
* RTL support for Urdu, Arabic, Persian, Hebrew
* Elementor conflict prevention
* Import/Export and reset settings
* Accessibility: keyboard, ARIA, reduced motion
* Custom CSS and Custom JS fields for advanced users
* 7 ready-made presets (Modern eCommerce, Luxury, Colorful, Minimal, Organic Store, Business, Technology)
* Page-level display control with exclusions

= Compatibility =

* WordPress 5.8+
* WooCommerce 6.0+ (optional - header works without it)
* Gutenberg
* Elementor / Elementor Pro
* Classic Editor
* PHP 7.4+ (tested on 8.1, 8.2, 8.3)
* All modern browsers (Chrome, Firefox, Safari, Edge)
* Mobile and tablet devices

== Installation ==

1. Upload `nexora-advanced-header.zip` through WordPress → Plugins → Add New → Upload Plugin
2. Activate the plugin
3. Go to Appearance → Menus and assign a menu to "Nexora Primary Header Menu"
4. Navigate to Nexora Header in the admin sidebar to customize
5. The header appears automatically using default settings

== Frequently Asked Questions ==

= Does this require WooCommerce? =

No. WooCommerce is recommended for cart and shop features, but the header works without it. WooCommerce-specific features are automatically disabled if WooCommerce is not installed.

= Will this conflict with Elementor? =

No. If Elementor Pro Theme Builder has an active header, Nexora will not render a duplicate header automatically.

= Does it support RTL languages? =

Yes. Full RTL support is included for Urdu, Arabic, Persian, and Hebrew.
